# OpenResea

Free, self-hosted tools for charities, community groups and campaigns.

- **[Resea Canvass](https://github.com/openresea/canvass)**: door-to-door canvassing. Import addresses and residents, give volunteers a route code, and record doorstep conversations on any phone.
- **[Resea Calls](https://github.com/openresea/calls)**: volunteer phone banking. Callers get one contact at a time and record each conversation and survey answer.

Both are free for non-commercial use, and you host them yourself, so your data stays with you.
